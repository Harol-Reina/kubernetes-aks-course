# Parte IV: Observabilidad, Alta Disponibilidad e Integración

La parte final del curso cubre los aspectos operacionales que mantienen un cluster en producción: logging centralizado, monitoreo con Prometheus y Grafana, autoescalado, troubleshooting avanzado y automatización con CI/CD y GitOps.

Al completar esta parte, tendrás visibilidad completa sobre tu cluster con logging y métricas, sabrás configurar autoescalado para alta disponibilidad, resolver problemas de forma sistemática y automatizar despliegues con CI/CD y GitOps.
