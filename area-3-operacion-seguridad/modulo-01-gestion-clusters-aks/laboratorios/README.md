# 🔬 Laboratorios - Módulo 01: Gestión de Clústeres AKS

Laboratorios prácticos para dominar la gestión de clusters AKS.

---

## Índice de Laboratorios

| # | Laboratorio | Duración | Nivel | Descripción |
|---|-------------|----------|-------|-------------|
| 01 | [Crear y Administrar Cluster](lab-01-crear-administrar-cluster/) | 45 min | Básico | Crear cluster AKS, conectar kubectl, explorar componentes |
| 02 | [Node Pools y Scaling](lab-02-node-pools-scaling/) | 40 min | Intermedio | Gestionar node pools, configurar autoescalado |
| 03 | [Actualización y Mantenimiento](lab-03-actualizacion-mantenimiento/) | 35 min | Intermedio | Upgrade de K8s, drain de nodos, PDBs |
| **Resumen** | [**Lab Resumen: Gestión de Clusters**](lab-resumen-gestion-clusters/) | **60 min** | **Integral** | **Todos los conceptos en un solo lab guiado** |

---

## Ruta Recomendada

### 🟢 Principiante
Empieza por el **Lab Resumen** para obtener una visión general práctica de todos los conceptos.

### 🟡 Intermedio
Realiza los labs 01 → 02 → 03 en orden para profundizar en cada tema.

### 🔴 Certificación
Completa todos los labs y practica los escenarios de troubleshooting del Lab 03.

## Requisitos Generales

- Azure CLI v2.49+ (`az --version`)
- kubectl configurado (`kubectl cluster-info`)
- Para labs locales: Minikube con 2+ CPU y 4GB+ RAM
