# Parte I: Fundamentos de Virtualización y Docker

Esta primera parte sienta las bases tecnológicas y conceptuales para comprender Kubernetes. Recorremos la evolución desde servidores físicos y máquinas virtuales hasta los contenedores Docker, la tecnología sobre la que Kubernetes opera.

**Duración estimada**: 6 horas | **Capítulos**: 1-2

## Capítulos

| Cap | Título | Duración | Ruta |
|-----|--------|----------|------|
| 1 | [Virtualización Tradicional](modulo-1-virtualizacion/README.md) | 2-3h | `modulo-1-virtualizacion/` |
| 2 | [Docker y Contenerización](modulo-2-docker/README.md) | 3-4h | `modulo-2-docker/` |

## Resultado Esperado

Al completar esta parte, dominarás la creación y gestión de contenedores Docker, entenderás las tecnologías Linux subyacentes (namespaces, cgroups) y tendrás la base conceptual necesaria para abordar Kubernetes en la Parte II.
